# Tote 'O Recall (ex-Noublipo)

Application de liste de courses simple et fluide.  
**Accroche :** *La liste qui n'oublie rien !*

**Tote 'O Recall** (gratuit) : pubs discrètes.  
**Tote 'O Recall+** : achat unique (~3,99 €) — sans pubs + fonctions avancées.

Code technique : package `toteo`, flavors `toteo` / `toteo_plus`, Android `com.toteo.toteo`.

## Lancer

```bash
cd ~/Toteo
flutter pub get

# Linux (PC)
./run-linux.sh

# Android gratuit
./run.sh

# Android Plus
./run-plus.sh
```

## Build Play Store

Voir `docs/PLAY_STORE.md` puis `./build-aab.sh`.
